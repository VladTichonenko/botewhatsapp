# ⚡ Быстрое решение проблемы на Railway

## Проблема:
```
Error: Failed to launch the browser process: Code: 127
libglib-2.0.so.0: cannot open shared object file
```

## ✅ Решение за 3 шага:

### Шаг 1: Выберите Dockerfile в настройках Railway

1. Откройте ваш проект на Railway
2. Перейдите в **Settings** → **Service**
3. В разделе **"Build"** выберите **"Dockerfile"** вместо "Nixpacks"
4. Сохраните изменения

### Шаг 2: Перезапустите деплой

1. Перейдите в **Deployments**
2. Нажмите **"Redeploy"** (или удалите и создайте проект заново)
3. Дождитесь завершения сборки

### Шаг 3: Проверьте логи

После перезапуска в логах должно быть:
```
✅ Бот готов к работе!
📱 WhatsApp бот запущен и готов получать сообщения
```

И QR-код для авторизации.

---

## 🎯 Если не помогло:

1. **Убедитесь, что файл `Dockerfile` есть в корне проекта** (он уже создан)
2. **Проверьте, что выбран Dockerfile** в настройках Railway
3. **Попробуйте удалить и создать проект заново** на Railway
