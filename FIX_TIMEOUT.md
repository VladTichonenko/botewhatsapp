# 🔧 Исправление ошибки таймаута Puppeteer

## ❌ Ошибка:
```
⚠️ Ошибка опроса: Runtime.callFunctionOn истекло время ожидания. 
При необходимости увеличьте значение параметра 'protocolTimeout' 
в вызовах launch/connect для более длительного времени ожидания.
```

## ✅ Решение применено:

### Что исправлено в `index.js`:

Добавлены параметры таймаута в конфигурацию Puppeteer:

```javascript
puppeteer: {
  // ... существующие настройки ...
  protocolTimeout: 300000, // 5 минут для операций Puppeteer
  timeout: 60000 // 60 секунд для запуска браузера
}
```

### Что это делает:

- **`protocolTimeout: 300000`** - увеличивает время ожидания для операций Puppeteer до 5 минут
  - Решает проблему с таймаутами при опросе сообщений
  - Особенно важно на медленных серверах или при высокой нагрузке

- **`timeout: 60000`** - увеличивает время ожидания запуска браузера до 60 секунд
  - Помогает при медленном запуске Chrome на сервере

---

## 🔍 Почему это происходит:

- На серверах операции Puppeteer могут занимать больше времени
- Стандартный таймаут (30 секунд) может быть недостаточным
- Особенно при опросе большого количества чатов

## ✅ После исправления:

Ошибки таймаута должны исчезнуть, и бот будет стабильно работать даже при медленных операциях.

---

**Если ошибки продолжаются:** Можно увеличить `protocolTimeout` до 600000 (10 минут), но обычно 5 минут достаточно.
