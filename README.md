# WhatsApp Бот на Green-API

Чат-бот для WhatsApp с использованием Green-API.

## Настройка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` и добавьте ваши данные:
```
ID_INSTANCE=your_instance_id
API_TOKEN_INSTANCE=your_api_token
WEBHOOK_URL=http://your-server.com/webhook
PORT=3000
```

3. Запустите бота:
```bash
npm start
```

## О проблеме с ошибкой 466

### Проблема с контактами

Green-API и WhatsApp Business API имеют ограничение: **для отправки исходящих сообщений на номер, который не писал вам первым, этот номер должен быть в контактах вашего WhatsApp аккаунта**. В противном случае возникает ошибка 466.

### Решения:

1. **Входящие сообщения** (рекомендуется): Пользователь должен написать боту первым. После этого вы можете отвечать без проблем с контактами.

2. **Шаблонные сообщения**: Если ваш WhatsApp Business аккаунт проверен Facebook, вы можете отправлять шаблонные сообщения на любые номера (но только однократно в течение 24 часов).

3. **Добавление в контакты**: Перед отправкой сообщения добавьте номер в контакты WhatsApp аккаунта (вручную или программно через WhatsApp).

4. **Использование групп**: Сообщения в группах работают без ограничений.

## Структура проекта

- `index.js` - основной файл бота
- `green-api.js` - модуль для работы с Green-API
- `.env` - конфигурация (не включен в git)
