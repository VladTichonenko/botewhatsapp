# 🚀 Быстрый старт: Деплой WhatsApp бота

## ⚡ Быстрая инструкция

### Рекомендуемая платформа: Railway

1. Зайдите на [railway.app](https://railway.app) и зарегистрируйтесь
2. Создайте новый проект → "Deploy from GitHub repo"
3. Выберите ваш репозиторий
4. Добавьте переменные окружения в Settings → Variables:
   ```
   SERVER_URL=ваш_сервер_url
   BOT_PORT=3001
   NODE_ENV=production
   ```
5. Railway автоматически задеплоит проект
6. Проверьте логи → найдите QR-код → отсканируйте его в WhatsApp

**Готово!** Бот будет работать 24/7 и не будет засыпать.

## ⚠️ Важно

**Netlify и Vercel НЕ подходят** для WhatsApp ботов, так как они:
- Засыпают при отсутствии активности
- Не поддерживают постоянные соединения
- Имеют ограничения по времени выполнения

**Используйте:**
- ✅ Railway (railway.app) - **РЕКОМЕНДУЕТСЯ**
- ✅ Render (render.com)
- ✅ Fly.io (fly.io)
- ✅ VPS (DigitalOcean, AWS EC2)

## 🆘 Проблемы?

1. Проверьте логи на платформе
2. Убедитесь, что переменные окружения настроены
3. Проверьте статус: `GET /api/status`
4. Смотрите раздел "Решение проблем" в [DEPLOY.md](./DEPLOY.md)
