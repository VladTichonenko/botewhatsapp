# 📱 Инструкция по выкладке WhatsApp бота

2. ✅ Создан **health check endpoint** (`/api/health`) для мониторинга
3. ✅ Подготовлены конфигурационные файлы для деплоя
4. ✅ Добавлена поддержка переменных окружения

## 🚀 Как выложить проект:

### Вариант 1: Railway (РЕКОМЕНДУЕТСЯ - самый простой)

1. Зайдите на https://railway.app и зарегистрируйтесь (можно через GitHub)
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Выберите ваш репозиторий с ботом
4. Railway автоматически определит проект и начнет деплой
5. **ВАЖНО:** В Settings → Service → Build выберите "Dockerfile" (для поддержки Puppeteer)
6. В настройках проекта (Settings → Variables) добавьте переменные:
   - `SERVER_URL` = ваш URL сервера (если есть)
   - `BOT_PORT` = 3001
   - `NODE_ENV` = production
7. После деплоя откройте логи (Deployments → View Logs)
8. Найдите QR-код в логах и отсканируйте его в WhatsApp
9. Готово! Бот работает 24/7

> ⚠️ **Если возникла ошибка с Puppeteer (libglib-2.0.so.0):** См. [RAILWAY_FIX.md](./RAILWAY_FIX.md)

**Преимущества Railway:**
- ✅ Бесплатный тариф
- ✅ Не засыпает (постоянный сервер)
- ✅ Автоматический деплой из GitHub
- ✅ Простая настройка

### Вариант 2: Render

1. Зайдите на https://render.com и зарегистрируйтесь
2. New → Web Service
3. Подключите GitHub репозиторий
4. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** Free
5. В разделе Environment добавьте переменные окружения
6. В Advanced → Health Check Path укажите: `/api/health`
7. Нажмите "Create Web Service"
8. После деплоя проверьте логи и отсканируйте QR-код

### Вариант 3: VPS (DigitalOcean, AWS, и т.д.)

1. Подключитесь к серверу через SSH
2. Установите Node.js:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
3. Установите PM2:
   ```bash
   sudo npm install -g pm2
   ```
4. Клонируйте репозиторий:
   ```bash
   git clone ваш_репозиторий
   cd botewhatsapp
   ```
5. Установите зависимости:
   ```bash
   npm install
   ```
6. Создайте `.env` файл:
   ```bash
   nano .env
   # Добавьте переменные окружения
   ```
7. Запустите с PM2:
   ```bash
   pm2 start index.js --name whatsapp-bot
   pm2 save
   pm2 startup
   ```
8. Проверьте логи:
   ```bash
   pm2 logs whatsapp-bot
   ```

## 🔧 Решение проблемы с "засыпанием"

Бот теперь имеет встроенный механизм keep-alive, который:
- Автоматически делает запросы к `/api/health` каждые 30 секунд
- Предотвращает "засыпание" на serverless платформах

### Дополнительно (опционально):

Можно настроить внешний сервис для пинга:

1. **UptimeRobot** (https://uptimerobot.com):
   - Создайте бесплатный аккаунт
   - Добавьте монитор типа "HTTP(s)"
   - URL: `https://ваш-домен.com/api/health`
   - Интервал: 5 минут

2. **Cron-job.org** (https://cron-job.org):
   - Создайте задачу
   - URL: `https://ваш-домен.com/api/health`
   - Расписание: каждые 5 минут

## ⚠️ Важные замечания:

1. **Netlify и Vercel НЕ подходят** для WhatsApp ботов:
   - Они засыпают при отсутствии активности
   - Не поддерживают постоянные соединения
   - Имеют ограничения по времени выполнения

2. **Используйте платформы с постоянным сервером:**
   - ✅ Railway (railway.app) - **РЕКОМЕНДУЕТСЯ**
   - ✅ Render (render.com)
   - ✅ Fly.io (fly.io)
   - ✅ VPS (DigitalOcean, AWS EC2)

3. **Переменные окружения:**
   - Никогда не коммитьте `.env` файл в Git
   - Используйте переменные окружения на платформе деплоя

## 🐛 Решение проблем:

### Бот не отвечает:
1. Проверьте логи на наличие ошибок
2. Проверьте статус: `GET /api/status`
3. Убедитесь, что QR-код отсканирован

### Бот "засыпает":
1. Убедитесь, что keep-alive работает (проверьте логи)
2. Настройте внешний сервис для пинга (UptimeRobot)
3. Для Render: включите Health Check в настройках

### Ошибки авторизации:
1. Удалите папку `.wwebjs_auth` на сервере
2. Перезапустите бота
3. Отсканируйте QR-код заново
