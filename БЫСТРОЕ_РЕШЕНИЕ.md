## ✅ Решение (выберите один вариант):

### Вариант А: Автоматическое (РЕКОМЕНДУЕТСЯ)

1. **Закоммитьте изменения:**
   ```bash
   git add railway.json Dockerfile
   git commit -m "Fix Puppeteer"
   git push
   ```

2. **Railway автоматически пересоберет** с Dockerfile

3. **Готово!** Проверьте логи через 2-3 минуты

### Вариант Б: Вручную в Railway

1. Откройте проект на Railway
2. **Settings** → **Service** → **Build** → выберите **"Dockerfile"**
3. Сохраните
4. **Deployments** → **"Redeploy"**

---

### Вариант В: Использовать готовый образ Puppeteer

1. Переименуйте `Dockerfile.puppeteer` → `Dockerfile`
2. Закоммитьте и запушьте
3. Railway пересоберет автоматически
